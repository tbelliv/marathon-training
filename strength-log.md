# Strength log — session load

COROS scores strength by heart rate, so a 57-minute session with 41 sets at 89 bpm reads 13. This ledger uses session RPE (Foster): **load = minutes × effort on a 0–10 scale.** It is the standard measure for strength load in sports science and it tracks tissue stress, which is what the gym is for. Send one number after each session (effort 0–10) and the row gets filled.

Scale: 2 = light PT, 4 = normal Thursday, 5–6 = normal Monday, 7 = a heavy Monday block in January, 8+ = too much for a runner mid-block.

## Rules for reading it

- A Monday in the November–January block should land 300–450. Above 450 means the lifting is starting to cost the running.
- Thursday should stay under 200.
- Weekly strength load above about 650 while running 60+ miles is the warning line.
- Deadlift top set is logged every Monday; bar speed note (fast / slowing / grinding) decides the next week's load.
